description: BA Assistant — condensed phase structure for time-critical initiatives
---
Run the BA Assistant `/fast-track` command: switch the **active** initiative to a condensed phase structure for time-critical work.

This is a mid-initiative mode switch for an initiative already past Phase 0, not the Lean/Standard/Full complexity tier chosen once at the Phase 0 exit gate (`~/.cursor/skills/ba-assistant/sub-skills/ba-intake-reviewer/SKILL.md`). Use `/fast-track` when an initiative already in flight turns out to be more time-critical than first assessed.

1. Ask via `AskQuestion` which remaining phase gates or analysis steps are being compressed or skipped for the rest of this initiative.
2. Log the activation as a decision in `initiative-tracker.md` (owner, date, status, which gates are affected), using the existing "proceed at risk, log the decision" pattern (`~/.cursor/skills/ba-assistant/instructions.md` Operating Principles).
3. State back to the user, in the same reply, exactly which analysis steps are being compressed or skipped, so the trade-off is visible rather than silent.
4. Does not retroactively skip the Phase 0 exit gate or PM approval if that hasn't happened yet, it only affects gates from this point forward.
