# Install BA Assistant

1. Read and follow `~/.cursor/skills/ba-assistant/sub-skills/ba-install/SKILL.md`
   if it exists. Otherwise read `skills/ba-assistant/sub-skills/ba-install/SKILL.md`
   from this package repo, or clone
   `https://github.com/Jess-Gibson/ba-assistant-cursor-skill` first.
2. Run `tools/install-ba-assistant.py --apply` (dry-run first if helpful).
3. Verify skills, rules, commands, hooks, `_workstream`, and `initiatives/`.
4. Immediately run personalisation via `sub-skills/ba-setup/SKILL.md`.
5. Offer workboard, meeting debrief, first initiative, or MCP help next.
