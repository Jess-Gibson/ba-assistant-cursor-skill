## Release checks

- [ ] Reader job is distinct. A link or section is used instead if a page does not earn its place.
- [ ] Content approval covers the facts and reader usefulness.
- [ ] Release approval covers the exact frozen source, title, format, and destination.
- [ ] The published copy has no local paths, relative links, placeholders, or stale draft wording.
- [ ] A long page has been measured after conversion and split at meaningful reader boundaries if needed.
- [ ] The operation is correctly routed: Markdown, HTML paste, or manual editor micro-edit.
- [ ] The page was read back after publication.
- [ ] Parent, title, first reader section, critical facts, tables, and links were checked.
- [ ] Local mirror and page registry record the live URL, page ID, source version, reviewer, and verification date.
